# 維修接單台

同一個網址，兩個分頁：**接單**（店面工單）與**需求雷達**（網路線索）。
線索談成可一鍵轉成工單。畫面每 60 秒自動更新。

網址：https://claude.ai/code/artifact/722a688e-5ace-4be8-9856-bcd98bd13e71

## 接單（店面主用）

工單流程：`待檢測 → 報價中 → 維修中 → 待取件 → 已完成`，客戶不修按「未成交」。
每張單只有一顆綠色按鈕推進下一階段，站在櫃檯單手就能操作。

| 功能 | 說明 |
|---|---|
| 快速開單 | 姓名、電話、機型、故障、報價、預計完成時數；機型與常見故障有快選鈕 |
| 單號 | 自動產生 `R<YYMMDD>-NN` |
| 逾期偵測 | 超過預計完成時間自動紅框、排到最上面，統計列同步顯示 |
| 撥號 | 電話是 `tel:` 連結，手機上點了直接撥 |
| 取件通知話術 | 待取件的單一鍵產生通知文字，可複製貼到 LINE |
| 報價話術 | 報價中的單一鍵產生報價說明 |
| 統計 | 待取件、店內在修（含逾期數）、今日進單、今日營收 |
| 搜尋 | 客戶、電話、單號、機型、故障、備註 |

## 需求雷達（網路線索）

保留原評分系統：規格第五節的加減分、分數拆解、可編輯關鍵字、
LINE 額度門檻自動調整（≥180 升到 85 分、≥195 停推）、回覆話術生成。
線索卡上的「轉成工單」會帶入機型與故障描述，並把該線索標記為已成交。

## 每分鐘自動更新

`setInterval` 60 秒重讀資料庫、重算逾期與相對時間，右上角顯示最後更新時刻並閃一下。
切回分頁時（`visibilitychange`）也會立刻更新。正在填單時不會打斷輸入。

**注意**：自動更新是「重讀資料」，不是「自動抓 PTT」。
瀏覽器有同源政策、PTT／Dcard 未開放 CORS，前端 `fetch` 一定被擋，
爬蟲必須跑在 GitHub Actions（伺服器端），把結果送進資料庫或匯出 JSON 匯入。

## 儲存

Claude Artifact 上使用 db capability，工單跨裝置同步（櫃檯平板、手機看到同一份）。
其他環境自動退回 localStorage，功能相同但只存在該裝置。

## 匯入格式

```json
[{"title":"…","body":"…","source":"PTT MobileComm","url":"https://…","author":"abc","posted_at":"2026-09-04T10:00:00Z"}]
```

以 `url` 去重。同一個面板也可更新本月已用 LINE 額度。
